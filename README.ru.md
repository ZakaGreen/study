# Учебные задания по программированию

Мои университетские упражнения на **C, C++, Java и R**, собранные во время обучения прикладной информатике в FEI STU в Братиславе.

Это коллекция отдельных заданий, а не одно приложение. Примеры показывают мою практику с основами программирования, структурами данных, объектно-ориентированным программированием и статистикой.

Указатели и структуры в C поначалу было сложно представить. Изучение устройства памяти помогло в них разобраться, и в итоге я самостоятельно выполнил задания. Пример на C ниже — часть этой практики. В [лабораторных работах с xv6](https://github.com/ZakaGreen/xv6-labs-2026) я продолжаю изучать устройство операционных систем; задания также хранятся на [GitLab](https://gitlab.com/ilushkalubotin/xv6-xliubotin-2026).

## Запуск примера на C

При установленном GCC выполните из корня репозитория:

```bash
cd C_studying/Programming_2/zadanie4
gcc -std=c11 -Wall -Wextra z4.c data.c -o army-simulation
./army-simulation 0
```

Небольшой пример входных данных:

```text
1
Alice sword
1
Bob axe
```

Первое число — размер первой армии, за ним следуют её бойцы и экипировка. Вторая армия задаётся в том же формате. Аргумент `0` выводит созданные армии без проведения боя. Названия и характеристики экипировки определены в [data.c](C_studying/Programming_2/zadanie4/data.c).

Эта команда GCC и пример ввода проверены на Linux. Исходная конфигурация CMake ожидает другую структуру каталогов, поэтому для файлов в этом репозитории используйте команду выше.
